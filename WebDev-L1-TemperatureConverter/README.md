# 🌡️ TempFlow — Temperature Converter

A professional and responsive temperature converter web application that allows users to convert temperatures between **Celsius, Fahrenheit, and Kelvin**.

TempFlow was developed as part of the **Oasis Infobyte Web Development & Design Internship — Level 1, Task 3**.

---

## 📌 Project Overview

**TempFlow** is an interactive temperature conversion tool built with HTML5, CSS3, and Vanilla JavaScript.

The application provides instant temperature conversions along with educational information about the three major temperature scales. Users can enter a temperature, select the input unit, and view the equivalent values in Celsius, Fahrenheit, and Kelvin.

The project also includes input validation and absolute-zero handling to provide a reliable and user-friendly experience.
🎓 Educational Purpose
TempFlow is designed not only as a conversion tool but also as a small educational resource.
The website explains:
- Celsius
- Fahrenheit
- Kelvin
- Conversion formulas
- Temperature reference points
- Absolute zero
This makes the project useful for both practical conversion and basic temperature-scale learning.

## 🌡️ Temperature Scales

### Celsius (°C)

Celsius is commonly used around the world for weather and everyday temperature measurements.

**Reference points:**

- Water freezes at **0°C**
- Water boils at **100°C**

---

### Fahrenheit (°F)

Fahrenheit is commonly used for everyday temperature measurements in the United States.

**Reference points:**

- Water freezes at **32°F**
- Water boils at **212°F**

---

### Kelvin (K)

Kelvin is the scientific SI temperature scale. It begins at absolute zero.

**Reference points:**

- Absolute zero = **0 K**
- Water freezes at approximately **273.15 K**
- Kelvin is written without the degree symbol

Example:

```text
300 K
