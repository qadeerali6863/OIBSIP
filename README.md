## 3. 🌡️ TempFlow — Temperature Converter

A professional and interactive temperature converter that converts values between **Celsius, Fahrenheit, and Kelvin**.

The project also includes educational information about temperature scales, conversion formulas, reference points, and absolute zero.

### Technologies

- HTML5
- CSS3
- Vanilla JavaScript
- Responsive Web Design
- Google Fonts

### Key Features

- Celsius conversion
- Fahrenheit conversion
- Kelvin conversion
- Numeric input validation
- Unit selection
- Convert Temperature button
- Clear/Reset functionality
- Absolute-zero validation
- Displays all converted values
- Temperature scale information
- Conversion formulas
- Reference temperature points
- Responsive desktop and mobile design
- Clean and professional interface

**Project Folder:**

`WebDev-L1-TemperatureConverter/`
